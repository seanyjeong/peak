# Plan: 전체 학생 기록 관리 페이지

> **Feature**: all-student-records
> **Created**: 2026-02-25
> **Status**: Draft

---

## 1. 개요

학원 전체 학생의 최신 기록을 한눈에 볼 수 있는 관리 페이지.
종목별 오름/내림차순 정렬, 이름/학교/학년 검색, 상태 필터링을 지원한다.

## 2. 현황 분석

### 현재 상태
- **기록 측정 페이지** (`/records`): 시간대별 학생들의 기록 입력용 (반 배치 기반)
- **학생 상세** (`/students/[id]`): 개별 학생의 기록/통계 확인
- **리더보드 API** (`/peak/stats/leaderboard`): 종목별 Top N 조회 (UI 미구현)
- **최신기록 API** (`/peak/records/latest`): 학생별 종목별 최신 기록 조회

### 부족한 점
- 전체 학생 기록을 **테이블 형태**로 비교할 수 없음
- 종목 간 **교차 비교** 불가
- 상태별 필터링 + 검색 조합 불가

## 3. 요구사항

| FR-07 | 학생관리 페이지에서 진입 버튼 | 필수 |

## 4. 기술 분석

### 활용 가능한 기존 자원

| 자원 | 경로 | 활용 |
|------|------|------|
| 최신기록 API | `GET /peak/records/latest` | 학생별 최신 기록 조회 |
| 학생 목록 API | `GET /peak/students` | 학생 정보 + 상태 |
| record_types API | `GET /peak/record-types` | 종목 목록 |
| 상태 필터 패턴 | `useStudentList.ts` | 상태 필터링 로직 재사용 |
| 상태 배지 색상 | 학생관리 페이지 | 일관된 UI |

### 신규 개발 필요

| 항목 | 설명 |
|------|------|
| **페이지** | `/students/records` (PC) — 학생관리 하위 경로 |
| **API 수정** | `GET /peak/records/latest` — 전체 학생 대상 조회 지원 확인 |
| **컴포넌트** | 정렬 가능한 테이블 헤더, 검색/필터 바 |

### 데이터 흐름

```
[페이지 로드]
  ├─ GET /peak/students?status=all → 전체 학생 목록
  ├─ GET /peak/record-types → 종목 목록 (테이블 컬럼)
  └─ GET /peak/records/latest → 학생별 최신 기록
      ↓
[클라이언트 조합]
  학생 정보 + 기록값 → 테이블 렌더링
      ↓
[필터/정렬] (클라이언트 사이드)
  이름검색, 학교검색, 학년필터, 상태필터, 종목별정렬
```

## 6. 구현 계획

### Phase 1: API 확인/수정
1. `GET /peak/records/latest` 가 student_ids 없이 전체 조회 가능한지 확인
2. 필요시 전체 학생 최신 기록 반환하도록 수정

### Phase 2: 페이지 구현
1. `/students/records/page.tsx` 생성
2. 데이터 fetching: 학생 + 종목 + 최신기록 병렬 로드
3. 테이블 렌더링: 종목을 동적 컬럼으로
4. 값 포맷: 단위 표시, 기록 없으면 `-`

### Phase 3: 필터 & 정렬
1. 이름/학교 텍스트 검색 (includes, 대소문자 무시)
2. 학년 드롭다운 필터
3. 상태 버튼 필터 (기존 패턴 재사용)
4. 종목 컬럼 헤더 클릭 → 오름/내림차순 토글 (direction 고려)

### Phase 4: 진입점 추가
1. 학생관리 페이지에 "전체 기록 관리" 버튼 추가
