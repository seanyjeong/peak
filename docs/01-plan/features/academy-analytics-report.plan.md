# Plan: 학원 분석 리포트

> **Feature**: academy-analytics-report
> **Created**: 2026-03-21
> **Status**: Draft

---

## 1. 개요

학원의 학생 기록 데이터를 분석하여 **종목별 순위, 남/여 평균, 트렌드(상승/유지/하락)** 를 시각화하는 데이터 기반 분석 리포트.
PDF 다운로드를 지원하며, 순수 통계 계산 기반(AI 미사용)으로 구현한다.

### 핵심 가치
- 원장/관리자가 학원 전체 학생의 실력 분포와 추세를 한눈에 파악
- 데이터 기반으로 부족한 종목 파악 → 훈련 계획에 반영
- PDF로 학부모 상담 자료 활용 가능

## 4. 기술 분석

### 트렌드 분석 알고리즘

최근 5개 기록으로 **선형 회귀 기울기** 계산:

```
기울기 = Σ((xi - x̄)(yi - ȳ)) / Σ((xi - x̄)²)

- direction: 'higher' → 기울기 > threshold = 상승
- direction: 'lower'  → 기울기 < -threshold = 상승 (낮을수록 좋은 종목)
```

| 기울기 범위 | 분류 |
|------------|------|
| 양의 유의미한 변화 | 📈 상승 (Improving) |
| 변화 미미 | ➡️ 유지 (Maintaining) |
| 음의 유의미한 변화 | 📉 하락 (Declining) |

> threshold는 종목별 단위/스케일에 따라 정규화 필요

### PDF 생성 방식

| 방식 | 장점 | 단점 |
|------|------|------|
| **html2canvas + jsPDF** | 화면과 동일, 구현 간단 | 이미지 기반, 텍스트 선택 불가 |
| **@react-pdf/renderer** | 벡터 PDF, 텍스트 선택 가능 | 별도 컴포넌트 작성 필요 |
| **서버사이드 Puppeteer** | 정확한 렌더링 | 서버 리소스 사용, 설치 필요 |

**추천**: `html2canvas + jsPDF` (화면과 PDF 일관성 보장, 구현 간단)

### AI API 연동 판단

| 항목 | 순수 계산 | AI API |
|------|-----------|--------|
| 평균/순위/트렌드 | ✅ 정확, 빠름, 무료 | ❌ 불필요한 비용 |
| 코칭 코멘트 | ❌ | ✅ 가능 (v2 고려) |
| 응답 속도 | ~500ms | ~3-5초 |
| 비용 | 0원 | 호출당 과금 |

**결론**: v1은 순수 데이터 계산. 코칭 코멘트가 필요해지면 v2에서 AI 추가.

## 5. 리포트 구성 (세로 연속 스크롤)

```
┌─────────────────────────────────────────┐
│  📊 [학원명] 분석 리포트                  │
│  생성일: 2026-03-21                      │
│  총 기록: 2,081건 | 학생: 48명            │
├─────────────────────────────────────────┤
│                                         │
│  ── 섹션 1: 종목별 남/여 평균 ──          │
│  [막대 그래프: 종목별 M/F 평균 비교]       │
│  [테이블: 종목, 남평균, 여평균, 전체평균]   │
│                                         │
│  ── 섹션 2: 종목별 순위 ──               │
│  [종목 탭/리스트]                         │
│  [남자 Top 10 테이블]                    │
│  [여자 Top 10 테이블]                    │
│                                         │
│  ── 섹션 3: 트렌드 분석 ──               │
│  📈 상승 그룹 (N명)                      │
│  [학생명, 주요 상승 종목, 변화율]          │
│                                         │
│  ➡️ 유지 그룹 (N명)                      │
│  [학생명, 유지 종목]                      │
│                                         │
│  📉 하락 그룹 (N명)                      │
│  [학생명, 하락 종목, 변화율]              │
│                                         │
│  ── 섹션 4: 데이터 부족 안내 ──           │
│  ⚠️ 다음 학생은 종목별 기록 5개 미만으로   │
│  트렌드 분석에서 제외되었습니다.            │
│  [학생명, 종목, 현재 기록 수]             │
│                                         │
└─────────────────────────────────────────┘
```

> PDF는 이 레이아웃 그대로 세로 연속 출력 (페이지 나눔 없음)
