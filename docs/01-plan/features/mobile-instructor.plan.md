# Plan: Peak 모바일 강사용 리뉴얼

## 배경
현재 모바일은 기록측정 + 수업기록 2개 탭만 존재.
강사가 수업 중 폰으로 할 수 있는 일을 제대로 갖추되, **필요한 것만 깔끔하게**.

## 핵심 원칙
- 출석은 Paca가 메인 → Peak 모바일에서는 **내 반 학생 현황 보기**만
- 수업 중 필요한 기능에 집중
- 탭 4개 이하로 유지 (엄지 하나로 조작)

---

## 모바일 탭 구성 (제안)

### Tab 1: 📋 내 수업 (홈)
> 오늘 내가 맡은 수업의 모든 것을 한 화면에

- **내 반 학생 목록** (출석 상태 표시 - Paca에서 읽기 전용)
  - 출석/결석/지각 뱃지
  - 체험생 표시
- **오늘 수업 계획** (운동 목록, 체크리스트)
  - 운동 완료 체크 ✓
  - 환경 체크 (온도/습도)
- 시간대 전환 (오전/오후/저녁)

**왜 합치나**: 강사가 수업 시작할 때 "누가 왔지? 오늘 뭐 하지?"를 한 화면에서 확인

### Tab 2: 📝 수업 기록
> 수업 중 학생별 기록

- 학생별 컨디션 점수 (1~5 이모지)
- 학생별 메모 (간단 입력)
- 반별 필터

**기존 기능 유지** + UI 개선

### Tab 3: 🏅 기록 측정
> 종목별 기록 입력

- 종목 선택 → 학생 리스트에서 기록 입력
- 자동 최고기록 비교 (UPSERT)
- 학생별 / 종목별 모드 전환

**기존 기능 유지** + UI 개선

### Tab 4: 📊 통계 (선택)
> 내 반 학생들의 핵심 지표

- 주간 출석률 (Paca 데이터)
- 최근 기록 변화 추이
- 컨디션 트렌드

## 구현 우선순위

| 순위 | 기능 | 설명 | 난이도 |
|------|------|------|--------|
| 🔴 P1 | 내 수업 탭 | 학생목록 + 수업계획 통합 | 중 |
| 🟡 P2 | 수업기록 개선 | 기존 UI 다듬기 | 소 |
| 🟡 P3 | 기록측정 개선 | 기존 UI 다듬기 | 소 |
| 🟢 P4 | 통계 탭 | 주간/월간 요약 | 중 |

## 기존 대비 변경점

| 항목 | 현재 | 변경 후 |
|------|------|---------|
| 탭 수 | 2개 | 3~4개 |
| 수업계획 | 네비에 없음 | "내 수업" 탭에 통합 |
| 학생 출석 | 없음 | "내 수업" 탭에 읽기 전용 |
| 수업기록 | 있음 | UI 개선 |
| 기록측정 | 있음 | UI 개선 |
| 통계 | 없음 | 신규 (P4) |

## 필요한 백엔드 작업

### 새 API
- `GET /peak/mobile/my-class` - 내가 배치된 반 + 학생 + 출석 + 오늘 계획 한방 조회
  - 강사 ID 기준 → class_instructors에서 오늘 배치 조회
  - 해당 반 학생 + Paca 출석 상태 JOIN
  - 오늘 수업 계획 포함

### 기존 API 활용
- `GET /peak/assignments` - 반 배치 (이미 있음)
- `GET /peak/plans` - 수업 계획 (이미 있음)
- `POST /peak/training` - 수업 기록 (이미 있음)
- `POST /peak/records/batch` - 기록 저장 (이미 있음)

## 리스크 & 고려사항
- 강사의 instructorId가 JWT에 있어야 함 (현재 userId만?)
- 원장(owner)은 모든 반 볼 수 있어야 함
- 오프라인 지원? → PWA 캐시로 최소한만
