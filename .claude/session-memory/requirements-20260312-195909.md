# Plan: 기록 종목 범위 검증 (record-type-range-validation)

## Context

기록 측정 시 잘못된 값이 저장되는 문제 발생 (10m왕복달리기에 227초, 메디신볼 106m 등).
종목별 허용 범위(min_value, max_value)를 설정하고, 범위 밖 입력 시 경고를 표시하여 오입력을 방지한다.

## 수정 범위

### 1. DB 스키마 변경
**파일**: `database/schema.sql` (문서용) + ALTER TABLE 실행

`record_types` 테이블에 2개 컬럼 추가:
```sql
ALTER TABLE record_types
  ADD COLUMN min_value DECIMAL(10,2) DEFAULT NULL COMMENT '허용 최소값',
  ADD COLUMN max_value DECIMAL(10,2) DEFAULT NULL COMMENT '허용 최대값';
```
- NULL이면 범위 제한 없음 (기존 종목 호환)
- 예: 제자리멀리뛰기 min=50, max=350 / 10m왕복달리기 min=5, max=30
